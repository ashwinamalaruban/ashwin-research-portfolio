## Tips

- **Reuse OK**: you can copy `project-asphaltene.png` to `research-asphaltene.png` if you want to use the same image.
- **File extension**: `.png` and `.jpg` both work — just match what `index.html` references. Currently the page expects `.png` for research/project slots, `.jpg` for the hero, and `.jpeg` for the paper.
- **Aspect ratio**: research/project cards crop to 16:10. Hero portrait crops to 4:5. Paper thumbnail crops to ~3:4.
- **File size**: aim for under 300 KB per image. Big originals (e.g., your 2.5 MB `profile.jpg`) work but will slow first load.
