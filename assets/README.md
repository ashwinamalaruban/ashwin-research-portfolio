# assets/

Supporting files: CV, papers, images, slide thumbnails.

```
assets/
  CV_Ashwin.pdf         ← linked from hero "Download CV"
  CV_Ashwin.docx        ← editable Word version
  langmuir-2022.pdf     ← Langmuir 2022 paper PDF (linked from Publications)
  papers/               ← original-named copies
  thumbnails/           ← auto-generated talk thumbnails (one per talk PDF)
  images/               ← YOUR profile photo and research/project images go here
```

## Updating CV

When you regenerate `CV_Ashwin.docx`, also export to PDF and overwrite `CV_Ashwin.pdf`. Both files are linked from the page (PDF for download/preview, DOCX for editing).
